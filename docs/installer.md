# Установщик MVS OS

## Что это

Calamares — графический установщик, который используется в Debian,
Manjaro, KDE Neon и других дистрибутивах. MVS OS добавляет к нему свою
последовательность шагов и оформление.

Запуск: ярлык **«Установить MVS OS»** на рабочем столе или

```sh
mvs-install
```

Установщик работает только из Live-режима: если системы на диске нет
образа для распаковки, `mvs-install` честно скажет об этом и не запустится.

## Шаги

1. **Приветствие** — проверка места, памяти и питания.
2. **Язык и часовой пояс** — по умолчанию русский, Europe/Moscow.
3. **Клавиатура** — ru + us, переключение Alt+Shift.
4. **Диск** — выбор диска и разметка (стереть диск / вручную).
5. **Пользователь** — имя, логин и пароль. Пароль обязателен.
6. **Сводка** — список того, что будет сделано.
7. **Установка** — разметка, распаковка, загрузчик.
8. **Готово** — перезагрузка по желанию.

## Что происходит на диске

| Шаг | Модуль Calamares | Действие |
| --- | --- | --- |
| partition | `partition` | создаёт разделы по выбору пользователя |
| mount | `mount` | монтирует будущую систему в `/target` |
| unpackfs | `unpackfs` | распаковывает `/lib/live/mount/medium/live/filesystem.squashfs` |
| machineid | `machineid` | новый machine-id, чтобы машины не совпадали |
| fstab | `fstab` | `/etc/fstab` с `noatime` и защищённым EFI-разделом |
| locale/keyboard | `locale`, `keyboard`, `localecfg` | язык, раскладка, locale-gen |
| users | `users` | учётная запись в группе `sudo`, пароль обязателен |
| networkcfg | `networkcfg` | переносит настройки Wi-Fi из Live |
| hwclock | `hwclock` | часы в UTC |
| live-admin | `shellprocess` | снимает Live-правила, пересобирает initramfs, включает защиту |
| bootloader | `bootloader` | GRUB для UEFI или Legacy BIOS |
| umount | `umount` | размонтирует `/target` |

## Что делает шаг live-admin

Это единственное место, где установленная система отличается от Live
по безопасности. Скрипт (`/etc/calamares/modules/live-admin.conf`) внутри `/target`:

- удаляет `/etc/sudoers.d/90-mvs-live` (sudo без пароля только в Live);
- удаляет `/etc/polkit-1/rules.d/49-mvs-live.rules`;
- удаляет автологин LightDM;
- ставит `PRETTY_NAME` без пометки «Live»;
- включает `ENABLED=yes` для ufw и политику `DROP` на входящие;
- включает службы `lightdm`, `NetworkManager`, `ufw`, `apparmor`;
- удаляет пакеты `live-boot`, `live-config`, `live-tools`;
- пересобирает initramfs, чтобы в нём не осталось скриптов live-boot;
- убирает ярлыки «Установить MVS OS» из меню и с рабочего стола;
- проверяет `visudo -c`; при ошибке установка завершается с ошибкой.

Журнал: `/var/log/mvs-install.log` в установленной системе.

## Если установка не запускается

```sh
# проверить образ и правила Live
ls -l /lib/live/mount/medium/live/filesystem.squashfs /run/live/medium/live/filesystem.squashfs
cat /etc/sudoers.d/90-mvs-live
sudo calamares -d
```

Подробный журнал Calamares: `/root/.cache/calamares/session.log`.

## Ограничения

- Установка проверялась только статически (конфиги + CI). На реальном
  железе в рамках этого проекта она **не прогонялась** — это указано
  в `docs/testing.md`, а не спрятано.
- Шифрование диска (LUKS) в этой версии не включено в последовательность.
  Разметка вручную поддерживает шифрование, но отдельного шага нет.
- Secure Boot: установленная система использует подписанный shim, но
  Live-флешка требует отключения Secure Boot.

## Явное подтверждение

Ни один шаг не пишет на диск, пока пользователь не нажмёт «Установить»
на экране «Сводка». Calamares показывает выбранный диск и список
разделов, которые будут созданы или изменены.
